生词堆

生词堆怎么用

不熟的词点卡片右上角的星标，就会放进生词堆；在词库里也可以直接加。

「复习生词堆」不管有没有到期，会把堆里的词全部过一遍。评为「简单」的词会自动移出生词堆，其余的留着下次再练。

点单词可以打开详情，写例句、录发音。

掌握程度分级

复习间隔怎么算

每次评分决定下次出现的时间：「忘了」当天重来；「模糊」间隔略增；「记得」按 1 → 3 → 约 7 → 约 18 天递增；「简单」跳得更远。

间隔达到 30 天以上的词算「精通」。

多设备同步

用同一个邮箱登录，iPhone、iPad 和电脑就共用同一份学习进度、自录单词和我的文章。只用邮箱来登录，不发其他邮件，也不收集别的信息。隐私说明

邮箱登录还在准备中，开通后这里就能用。

第一次登录会自动创建账号。验证码 1 小时内有效。

已登录：

开启后，连网站管理者也看不到你的内容。忘了这个密码就无法恢复同步数据（本机数据不受影响）。

把数据加密后存进你自己的私有 GitHub 仓库。适合有 GitHub 账号、不想用邮箱的人。

已连接：

第一次设置（约 3 分钟）
  1. 在 GitHub 新建一个私有仓库，名字例如 entrelinhas-sync：github.com/new，选 Private。
  2. 新建一个 token：Fine-grained token。Repository access 选 Only select repositories → 只勾这个仓库；Permissions → Repository → Contents 选 Read and write。有效期最长一年，到期再换一个。
  3. 把仓库名和 token 填在下面，再想一个同步密码。每台设备都用同一个密码；忘了就解不开，没有找回办法。
